# Data Science Salary Dashboard

https://github.com/user-attachments/assets/56e912f3-cbd0-40d3-884f-6b761b179e55



An interactive Excel dashboard analyzing **32,000+ data-related job postings** from 2023.  
It helps explore salary trends across roles, countries, job types, and skills.

---

## 📊 What's Inside

| Sheet              | Purpose                                      |
|--------------------|----------------------------------------------|
| **Data**           | Full dataset (32,672 job postings)           |
| **Salary calculator** | Interactive tool to estimate salary by role, country & job type |
| **Country**        | Median salaries by country                   |
| **Title**          | Salary breakdown by job title                |
| **Type**           | Salary by employment type (Full-time, Contractor, etc.) |
| **Job_via**        | Job sources / platforms analysis             |
| **Data validation**| Lists used for dropdowns and filters         |

### Key Columns in the Dataset
- Job Title (short + full)
- Location & Country
- Work from home status
- Schedule type (Full-time, Contractor, Part-time, etc.)
- Salary (yearly average / hourly average)
- Company name
- Required skills
- Degree requirement & health insurance mentions
- Posting date & source platform

## 🛠️ How to Use

1. Open `Salary_dashboard.xlsx` in **Microsoft Excel** or **Google Sheets**
2. Go to the **Salary calculator** sheet
3. Use the dropdowns to select:
   - Job Title
   - Country
   - Job Type
4. Explore the summary sheets (**Country**, **Title**, **Type**) for quick insights
